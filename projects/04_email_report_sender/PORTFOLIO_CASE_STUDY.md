# 作品集案例：自动发送邮件报表

## 一句话介绍

我做了一个 Python 邮件报表发送工具，可以把自动生成的 Excel 报表作为附件，生成邮件预览，或在配置 SMTP 后自动发送给客户和团队。

## 客户场景

很多客户已经有日报、周报或月报文件，但仍然需要人工打开邮箱、写标题、添加附件、选择收件人并发送。这个动作重复、容易漏发，也不方便和定时任务结合。

## 我的解决方案

我用 Python 做了一个命令行工具，把“发送报表”变成可复用流程。默认先生成 `.eml` 邮件预览，确认无误后再用 `--send` 通过 SMTP 发送。

自动化流程：

1. 读取指定 Excel 报表。
2. 构造邮件标题、正文、发件人和收件人。
3. 把报表作为附件加入邮件。
4. 默认生成邮件预览文件。
5. 配置 SMTP 后可以真正发送邮件。
6. 真实密码保存在本地配置，不提交到 GitHub。

## 交付内容

- 可运行的 Python 邮件发送脚本。
- 示例 SMTP 配置文件。
- 示例邮件预览文件。
- 项目 README 和运行说明。
- 自动化测试，覆盖附件邮件构造、预览保存和 SMTP 发送逻辑。

## 可以直接发布的作品集文案

我做了一个“自动发送邮件报表”项目，用 Python 把 Excel 报表自动作为附件发送给指定收件人。工具支持先生成邮件预览，确认标题、正文和附件无误后，再通过 SMTP 真正发送。

这个项目模拟的是客户非常常见的需求：自动生成报表后，希望系统每天或每周自动把结果发到邮箱。它可以和 Excel 自动化、API 报表、数据采集报表组合使用，形成“生成报表 -> 发送报表”的完整自动化流程。

技术点：Python、smtplib、EmailMessage、附件处理、环境变量配置、SMTP、密钥不入库、pytest 测试。
