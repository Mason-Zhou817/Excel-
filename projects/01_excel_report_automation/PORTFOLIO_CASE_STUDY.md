# 作品集案例：销售 Excel 自动化报表

## 一句话介绍

我做了一个 Python 自动化报表工具，可以把多个销售明细文件自动合并、清洗、去重，并生成带汇总表和图表的 Excel 报表，适合替代每周重复的手工统计工作。

## 客户场景

一个小型销售团队每周会收到多个销售 CSV/Excel 文件。负责人需要手动复制、合并、删除重复订单，再按商品品类统计收入。这个流程重复、容易出错，也很难稳定交付给老板或客户。

## 我的解决方案

我用 Python 做了一个命令行工具，客户只需要把原始销售文件放进 `input` 文件夹，然后运行一条命令，就能得到整理好的 Excel 报表。

自动化流程：

1. 批量读取多个销售文件。
2. 清理字段格式和异常数据。
3. 删除重复订单。
4. 计算每条订单收入。
5. 按品类和月份生成汇总。
6. 输出 Excel 报表和 CSV 汇总文件。

## 交付内容

- 可运行的 Python 脚本。

## 样例成果

当前示例数据中，工具读取 12 行原始订单，自动去掉 1 条重复订单，输出 11 条清洗后的有效订单，并生成 3 个品类的收入汇总。

品类收入结果：
