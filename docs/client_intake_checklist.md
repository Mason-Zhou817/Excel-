# 客户需求确认清单

每个项目开工前先确认这 5 件事，能少踩很多坑。

## 1. 输入是什么

- 文件类型：Excel、CSV、JSON、网页、API、数据库？
- 样例数据：至少要 3-10 行真实结构的样例。
- 数据来源：客户手动上传、固定目录、公开 API、第三方系统？

## 2. 输出要什么

- 输出格式：Excel、CSV、网页、数据库、邮件、API？
- 字段和列名：是否有固定模板？
- 是否需要图表、汇总页、筛选器、多个 sheet？

## 3. 规则是什么

- 怎么判断重复数据？
- 空值、错误值、异常值怎么处理？
- 统计口径是什么？例如收入是否含税、时间按下单还是付款。

## 4. 截止时间和验收标准

- 最晚什么时候交付？
- 客户如何验收？给样例输出、截图或验收表。
- 修改范围包括几轮？超过范围如何加价？

## 5. 安全和付款

- 尽量使用平台托管或阶段付款。
- 不接违法采集、绕验证码、撞库、破解、侵犯隐私的需求。
- 不要让客户只给口头需求，至少保留聊天记录或简短需求文档。
