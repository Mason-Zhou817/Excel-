# 接单投递模板

## 中文短模板

你好，我看了你的需求，本质上是把数据从「输入来源」整理成「目标输出」，并减少手工处理。

我可以这样做：

1. 先根据你提供的样例数据确认字段和清洗规则。
2. 用 Python 写一个可重复运行的脚本。
3. 输出 Excel/CSV 报表，并附上运行说明。
4. 交付前用你的样例数据跑一遍，确认结果和口径一致。

为了准确报价，我想先确认 5 点：

- 输入文件或接口是什么？
- 输出模板是否固定？
- 是否需要去重、合并、筛选或图表？
- 数据量大概多少？
- 希望什么时候交付？

如果需求范围明确，我可以先做一个小样例给你确认方向。

## English Short Template

Hi, I read your project description. It looks like you need a repeatable Python workflow to turn your input data into a clean report/output.

I can help with:

1. Reviewing your sample input and confirming the transformation rules.
2. Building a Python script that can be run repeatedly.
3. Exporting the result to CSV/Excel with clear setup instructions.
4. Testing the script against your sample data before delivery.

To estimate accurately, could you share:

- What is the input source?
- What output format do you need?
- Do you need deduplication, filtering, merging, or charts?
- Roughly how many rows or files are involved?
- What is your target deadline?

For a small, well-scoped task, I can usually deliver a first working version quickly.

## Fiverr Gig 标题示例

- I will automate your Excel reports with Python
- I will clean, merge, and deduplicate CSV or Excel files
- I will build a Python script to call an API and export reports
- I will collect public web data into CSV or Excel

## 个人简介示例

我专注 Python 自动化、Excel/CSV 数据处理和简单 API 集成。可以帮你把重复的手工复制、清洗、合并和报表整理流程做成可重复运行的脚本，并提供清楚的运行说明和样例输出。
