# 作品集发布清单

每个作品发布前都补齐这些材料。

## 必备材料

- 项目标题：客户能一眼看懂，不要只写技术名词。
- 问题描述：客户原来手工做什么。
- 解决方案：脚本如何自动化。
- 输入样例：截图或样例文件。
- 输出样例：Excel/CSV/报表截图。
- 运行说明：3-5 条命令即可。
- 演示视频：1 分钟，展示输入、运行、输出。

## 推荐截图

- 终端运行成功截图。
- 输入文件截图。
- 输出 Excel 报表截图。
- 代码仓库 README 截图。

## 发布文案结构

1. 我解决了什么重复工作。
2. 输入是什么，输出是什么。
3. 自动化后节省了什么时间。
4. 客户可以如何改造成自己的业务。

## 不建议展示

- 没有说明的代码截图。
- 客户敏感数据。
- 违法采集或绕过限制的案例。
- 只写“我会 Python、pandas、requests”。
