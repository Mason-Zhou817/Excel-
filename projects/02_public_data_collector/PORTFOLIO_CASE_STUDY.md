# 作品集案例：公开数据关键词采集报表

## 一句话介绍

我做了一个 Python 公开数据采集工具，可以根据关键词调用允许访问的公开搜索 API，自动整理文章标题、来源链接和讨论热度，并输出 Excel 汇总报表。

## 客户场景

一个内容或研究团队希望关注多个公开话题的最新讨论，用于选题、趋势观察和资料收集。负责人原本需要逐个搜索关键词，再手动复制文章标题、链接和互动数据到 Excel。

## 我的解决方案

我用 Python 做了一个可重复运行的关键词采集报表工具。用户把关键词写入配置文件，或在终端临时输入关键词，程序就会通过公开 API 获取结果，并输出带汇总、明细和失败记录的 Excel。

自动化流程：

1. 读取关键词列表。
2. 调用公开搜索 API 获取文章结果。
3. 整理标题、来源域名、链接、作者、积分、评论数和发布时间。
4. 网络请求失败时自动重试。
5. 汇总每个关键词的结果数量和讨论指标。
6. 导出 Excel 报表及汇总图表。

## 交付内容

- 可运行的 Python 脚本。
- 示例关键词配置文件。
- 带图表的 Excel 示例报表。

## 演示成果

示例配置包含 `python`、`automation`、`data pipeline` 三个关键词。运行时为每个关键词采集最多 10 条公开结果，成功示例共生成 30 行文章明细。

输出工作表：

- `keyword_summary`：关键词结果数量和讨论热度汇总。
- `stories`：可继续筛选的公开文章明细。
- `api_errors`：未成功请求的关键词记录。

数据来自实时公开搜索，文章标题和热度会随运行时间变化。
