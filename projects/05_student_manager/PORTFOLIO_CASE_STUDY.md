# SQLite 学生信息管理系统

## 项目简介

我做了一个基于 Python 和 SQLite 的学生信息管理系统，可以把学生资料从 CSV 导入数据库，并支持查询、筛选、统计和导出。

## 解决的问题

很多小机构或课程项目一开始会用 Excel 维护学生资料，但数据一多就容易出现查询慢、重复维护、统计麻烦的问题。这个工具把学生资料保存到 SQLite 数据库里，让信息管理更稳定，也方便后续升级成网页系统。

## 核心功能

- CSV 导入学生资料。
- SQLite 持久化保存。
- 添加、查询、筛选学生。
- 按专业统计人数和平均年龄。
- 导出学生名单 CSV。

## 技术点

- Python 命令行工具
- SQLite 数据库
- CSV 导入导出
- CRUD 数据操作
- 简单统计报表

## 可继续升级

这个项目后续可以升级成 Flask / Streamlit 页面，或者扩展成绩管理、课程管理、缴费记录和 Excel 报表导出。
