# 可售卖服务清单

## 入门价服务

- Excel/CSV 合并清洗：去重、改格式、字段拆分、生成新表。
- 批量文件处理：重命名、分类、转格式、提取文本。
- 公开 API 数据整理：把接口数据导出为 Excel/CSV。
- 简单网页公开数据采集：只做合规公开数据。

## 中档服务

- 自动报表：多 sheet、图表、固定模板、定期生成。
- 数据同步：Airtable、Notion、Shopify、CRM、ERP 等 API 对接。
- 小型后台接口：FastAPI/Flask + SQLite/PostgreSQL。
- 自动邮件：定时生成报表并发送。

## 暂时不要接

- 绕验证码、登录墙、付费墙。
- 批量注册、刷量、撞库、破解。
- 数据来源和验收标准不清楚的“帮我做个系统”。
- 需要长期维护但不愿意阶段付款的单。

## 报价参考

- 海外小单：30-150 美元起，先做固定价。
- 国内小单：300-1500 元起，看数据量和沟通成本。
- 复杂项目：拆成需求确认、原型、第一版、修改和交付几个阶段。
