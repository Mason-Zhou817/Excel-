### 标题

### 简短简介

你好，我可以帮你把 Excel、CSV、公开数据或 API 数据自动整理成可复用报表，并按需自动发送给指定人员。适合销售报表、库存报表、运营日报、公开数据采集、API 数据同步和重复办公流程自动化。

### 我可以做什么

- Excel/CSV 合并、清洗、去重、字段整理。
- 销售、库存、订单、运营数据自动汇总。
- API 数据拉取，并导出为 Excel/CSV。
- 合规公开数据采集和关键词数据整理。
- 自动生成 Excel 报表和图表。
- 自动发送邮件报表。
- 为脚本补清楚的运行说明，方便你后续复用。

### 技术栈

Python、pandas、openpyxl、requests、smtplib、pytest、CSV、Excel、JSON、SMTP。

### 工作方式

1. 先确认输入文件/API、输出格式、字段规则和交付时间。
2. 用样例数据做第一版可运行脚本。
3. 输出 Excel/CSV 或邮件预览，给你确认结果。
4. 根据反馈做小范围调整。
5. 交付脚本、示例文件和运行说明。

- 绕过验证码、登录墙、付费墙或反爬限制。
- 未授权采集私人数据、账号数据或敏感信息。
- 需求边界不清楚，但要求一次性包办大型系统。
- 不愿提供样例数据或验收标准的任务。
