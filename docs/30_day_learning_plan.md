# 30 天接单准备路线

默认每天 1-2 小时，目标是在 30 天内具备投小单的作品和话术。

## 第 1 周：跑通基础

- Day 1：创建虚拟环境，安装依赖，跑通 3 个项目。
- Day 2：学习文件读写、路径、异常处理。
- Day 3：学习 pandas 读取 CSV/Excel。
- Day 4：改造 Excel 项目的字段和统计口径。
- Day 5：学习 requests、HTTP、JSON。
- Day 6：改造公开数据采集项目的输出字段。
- Day 7：整理第一个作品截图和 README。

## 第 2 周：做成客户能用的工具

- 增加命令行参数。
- 增加错误提示和日志。
- 增加样例输入输出。
- 学会用 pytest 写基础测试。
- 学会写交付说明。

## 第 3 周：包装作品集

- 录 3 个 1 分钟演示视频。
- 写 3 个项目介绍。
- 准备中英文个人简介。
- 注册或完善 Upwork、Fiverr、程序员客栈、电鸭、猪八戒资料。

## 第 4 周：开始投小单

- 每天筛 5-10 个小项目。
- 只投需求清楚、1-3 天能做完、付款方式明确的单。
- 每次投递都按客户需求改模板，不群发。
- 记录客户问题，反向补作品和 FAQ。

## 升级方向

- 有 3-5 个交付后，学习 FastAPI/Flask 和数据库。
- 有 API 项目经验后，学习定时任务、Docker 和简单部署。
- 再往后可以做 AI API 集成、RAG、自动化工作流。
